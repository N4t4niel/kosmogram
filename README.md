# Kosmogram

Astrologický program v češtině pro Windows: horoskop, tranzity, progrese, solární návrat, kalendář a vztahy, s českými výklady a nápovědou. Vychází z programu Astrolog 8.00 Waltera D. Pullena.

Instalátor je ve [vydáních](https://github.com/N4t4niel/kosmogram/releases). Zdrojový kód, sestavení a licence jsou ve složce [`app`](app/README.md).
